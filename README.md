# 🛡️ Démo « Sarah, 15 ans »

> Un support de **sensibilisation** interactif sur les dangers du numérique pour les jeunes —
> pensé pour être projeté en direct devant un public (éducateur·rices, familles, professionnel·les
> de la protection de l'enfance).

On suit **Sarah**, une ado fictive, et on montre, étape par étape, ce qu'un inconnu peut
reconstituer sur elle à partir d'informations **publiques**, puis comment une simple hygiène
numérique (compte privé, bon mot de passe, 2FA, prudence) **bloque** l'attaque.

⚠️ **Tout est fictif et non fonctionnel.** « Sarah » n'existe pas, aucune donnée n'est collectée,
aucun mot de passe n'est lu, aucune attaque réelle n'est réalisée. Les écrans sont des
**reconstitutions pédagogiques**, sans aucune méthode reproductible.

---

## ▶️ Lancer la démo
1. Télécharger / cloner le dossier.
2. Double-cliquer sur **`0-accroche.html`** (ça s'ouvre dans le navigateur — **aucune connexion requise**, marche en mode avion).
3. **F11** pour le plein écran.

### Commandes clavier
| Touche | Action |
|---|---|
| `Espace` ou `→` | avancer |
| `←` | reculer |
| `R` | recommencer la scène |
| `F11` | plein écran |
| `W` | cacher / afficher le filigrane « DÉMO » |

*(Scène « connexion » : `A` = défilement auto, `+` / `-` = vitesse.)*

Tout s'**enchaîne automatiquement** d'une scène à l'autre : il n'y a qu'à appuyer sur `Espace`.

## 🎬 Le déroulé
| # | Scène | Message |
|---|---|---|
| 0 | Accroche | « Sarah n'existe pas » — cadre fictif |
| 1 | Profil + recherche + fiche | tout est **public**, rien n'est « piraté » |
| 2 | Des infos au mot de passe | ses infos **deviennent** ses mots de passe |
| 3 | Connexion | un mot de passe faible et ça s'ouvre |
| 4 | Plan B | la vraie faille : la **confiance** |
| 5 | Sextorsion | sobre + **anti-honte** ; rien ne s'efface |
| 6 | On rembobine | compte privé + mdp long + **2FA** → ça échoue |
| 6b | Internet n'oublie pas | même privé, c'est **archivé** (Wayback) → agir tôt |
| 7 | Signaux d'alerte | repérer, réagir, relais (119 / ASE) |
| 8 | Clôture | 4 règles + ressources |
